# موقع إدارة مزرعة ليوا 77 — النسخة السحابية

هذه النسخة جاهزة لتخزين سجلات جميع العمال في قاعدة بيانات واحدة، وتشمل:

- الحصاد والإيرادات والجودة
- عدد الأشجار وحالتها
- الصيانة ومواعيدها القادمة
- الري واستهلاك المياه
- مهام العمال
- المصروفات
- مخزون الأسمدة والمبيدات وقطع الري
- اسم العامل الذي سجّل كل عملية
- تحديث مباشر بين الأجهزة، ونسخ احتياطي وCSV

## الإعداد السحابي

1. أنشئ مشروعاً مجانياً في Supabase.
2. افتح **SQL Editor**، الصق محتوى ملف `supabase-setup.sql`، ثم اضغط **Run**.
3. من **Project Settings → API** انسخ:
   - Project URL
   - Publishable / anon key
4. افتح `config.js` واستبدل القيمتين اللتين تبدأان بكلمة `PASTE_`.
5. غيّر `accessPin` من `7777` إلى رمز خاص بالمزرعة.

لا تستخدم `service_role` أو أي Secret Key داخل الموقع.

## نشر الموقع كرابط

ارفع جميع الملفات في هذا المجلد إلى GitHub Pages أو Netlify أو Vercel. لا يوجد build step.

### GitHub Pages

1. أنشئ مستودعاً عاماً باسم `liwa77-farm`.
2. ارفع جميع الملفات إلى المجلد الرئيسي للمستودع.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch** ثم `main` و `/root`.
5. سيظهر رابط الموقع بعد النشر.

## ملاحظة أمنية

رمز الدخول داخل الواجهة يمنع الاستخدام العرضي، لكنه ليس حماية قوية ضد شخص تقني يملك ملفات الموقع. هذه النسخة مناسبة لسجل تشغيلي داخلي بسيط. للبيانات الحساسة يجب إضافة حساب مستقل لكل عامل وصلاحيات Supabase Auth.
